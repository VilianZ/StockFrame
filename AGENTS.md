# AI Trading Research project instructions

## Development logging

- Simpan log pengembangan secara append-only di `devlog/DEVELOPMENT_LOG.md`.
- Buat tepat satu entry untuk setiap task yang mengubah implementation files.
- Tulis narasi log dalam Bahasa Indonesia.
- Field `Human Prompt` harus berupa paraphrase yang cukup lengkap untuk
  menjelaskan maksud pengguna, tetapi tidak menyalin prompt mentah secara
  hampir keseluruhan.
- Jangan mencatat credential, token, secret, authorization header, atau data
  pribadi.
- Gunakan checklist milestone yang sesuai dan hanya centang item setelah
  implementasi serta validasinya benar-benar selesai.
