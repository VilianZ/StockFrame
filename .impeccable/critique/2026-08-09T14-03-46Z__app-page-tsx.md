## Design Specificity Verdict

StockFrame tetap terasa authored dan product-specific. Penggantian grafik bullish menjadi pulsa Data ke Engine ke Interpretasi memperbaiki coherence merek. Detector statis menemukan 0 issue pada page dan research desk, tetapi runtime browser menemukan clipping dan overlap yang tidak dapat dideteksi secara statis.

## Overall Impression

Perubahan memperbaiki inti semantik F2, tetapi acceptance belum dapat ditutup. Dua masalah terbesar adalah mobile hero yang masih terpotong dan klaim interaction testing yang sebenarnya hanya unit/state-contract testing.

## What's Working

- Signal tidak lagi menyiratkan kenaikan harga.
- Ambiguity memiliki aksi Ubah pencarian yang eksplisit.
- Recovery dibedakan menjadi retry, edit, dan none.
- Empty validation berhasil di desktop dan mobile tanpa network call.

## Priority Issues

### P1 - Mobile hero masih terpotong

Pada viewport efektif 375px, main mempunyai scrollWidth 480px. Headline dan lede melewati sisi kanan sekitar 38px, evidence artifact sekitar 47px, dan signal artwork sekitar 105px. Overflow menyembunyikan masalah alih-alih menyelesaikannya.

### P1 - Interaction testing belum membuktikan UI behavior

Test baru hanya memanggil helper analysis-state. Tidak ada rendered component atau E2E test untuk duplicate click, abort, preserved values, candidate click/resubmission, retry visibility, focus movement, dan aria-live. Checklist F2 terlalu optimistis.

### P2 - Signal labels overlap pada desktop

Label DATA bertabrakan dengan hero copy dan label INTERPRETASI bertabrakan dengan kartu interpretasi pada 1440x900.

### P2 - Timeout recovery copy dan aksi tidak selaras

Copy meminta fokus dipersingkat, tetapi tombol retry langsung mengirim ulang input yang sama.

### P2 - Disclosure ilustratif dapat dibuat lebih tegas

Contoh ilustratif sudah ada, tetapi angka realistis, tanggal presisi, dan confidence 82% masih dapat dipersepsikan sebagai fixture aktual. Gunakan satu disclosure eksplisit bahwa seluruh kartu merupakan contoh sintetis dan bukan data live.

## Persona Red Flags

- Casey mobile kehilangan bagian headline dan artwork karena clipping.
- Sam keyboard/screen-reader belum memiliki regression interaction nyata untuk focus dan live announcements.
- Riley dapat menemukan mismatch timeout retry dan checklist yang melebihi bukti test.

## Minor Observations

- Brand header/footer dan secondary link memiliki hit-box di bawah 44px.
- Full report renderer tetap scope F3 dan bukan defect F2.
- Detector bersih tidak membuktikan layout runtime aman.

## Questions to Consider

- Apakah F2 harus ditutup berdasarkan source behavior saja, atau berdasarkan rendered component tests seperti yang diminta implementation plan?
- Haruskah signal line tetap sebesar sekarang jika labelnya mengganggu copy dan kartu evidence?
